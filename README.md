# Sunway Medical Centre Blood Donation Tracker

## Project Title

Sunway Medical Centre Blood Donation Tracker

## Project Description

The Sunway Medical Centre Blood Donation Tracker is a web application prototype developed to manage blood donation activities and blood inventory records. The system allows users to register and log in, view donation records, monitor blood stock levels, and access a dashboard containing charts and summaries. The project demonstrates the application of advanced web design principles, responsive layouts, content organisation, and data visualisation techniques using modern web technologies.

---

## Features Included

### 1. Authentication Page

- User Login page
- User Registration page
- Error message for invalid login credentials
- User data stored using Local Storage

### 2. Navigation Menu

- Responsive navigation bar
- Links between all pages
- Mobile-friendly menu using Bootstrap 5

### 3. Dashboard Page

- Welcome section
- Donation Trends Line Chart
- Blood Type Distribution Pie Chart
- Recent Donation Activity table
- Upcoming Donation Schedule

### 4. Data View Pages

#### Donations Page

- View donation records
- Search donor names
- Filter donations by status
- Table-based data presentation

#### Blood Inventory Page

- View blood stock information
- Search blood types
- Filter inventory by stock level
- Inventory summary cards
- Table-based data presentation

### 5. Settings Page

- View profile information
- Update personal details
- Change password
- Save account settings

### 6. Data Visualisation

- Donation Trends Chart (Chart.js)
- Blood Type Distribution Chart (Chart.js)

## Instructions to Test Login

### Testing Steps

## How to Run the System

1. Download or clone the project files.
2. Ensure all HTML files are located in the same folder.
3. Place the logo image inside the `images` folder.
4. Open `index.html` using any modern web browser.
5. Register a new account or log in using your credentials.
